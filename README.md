## ✨ Recursos Principais

- 🖥️ **Estética macOS & Terminal** — Janelas interativas estilo macOS com controles de fechar, minimizar e expandir.
- 🎨 **Paleta Escura Inspirada no Anytype** — Visual moderno com tons de grafite suave e accent verde neon.
- 📈 **Barra de Progresso & Scroll Spy** — Progresso de rolagem no cabeçalho e destaque automático da seção ativa no menu.
- 📁 **Filtro Dinâmico de Projetos** — Filtre por Produto, Security, Ferramenta, Data e Web com clique direto para repositórios GitHub e sites ao vivo.
- 🛡️ **Security Lab & Certificações** — Badges de certificações com links de verificação oficiais (Solyd, Desec, Red Team Leaders, IBM e XP Inc).
- 💼 **Open to Work Status** — Badge interativo de disponibilidade para oportunidades em engenharia de software.
- 📊 **Analytics First-Party & Umami** — Telemetria de visitas e eventos configurada via variáveis de ambiente.
- ⚡ **Alta Performance & SEO** — Estruturado para rápido carregamento, com sitemap.xml, robots.txt e meta tags Open Graph/Twitter atualizadas.

## 🛠️ Tecnologias & Arquitetura

```
Portfolio/
├── api/                  # Vercel Serverless Functions
│   └── track.js          # Proxy seguro para First-party Analytics
├── public/               # Ativos estáticos servidos diretamente
│   ├── favicon/          # Favicon (SVG, PNG 32px e 64px)
│   ├── robots.txt        # Configuração SEO
│   └── sitemap.xml       # Mapa do site para indexação
├── src/
│   ├── assets/           # Imagens de projetos e certificações (WebP)
│   ├── js/
│   │   ├── analytics.js  # Script de telemetria e integração Umami
│   │   └── app.js        # Lógica de interatividade (Nav, Scroll, Terminal, Filtros)
│   └── styles/
│       └── main.css      # Estilos globais e componentes (Design Tokens, Responsive)
├── .env.example          # Modelo de variáveis de ambiente
├── index.html            # Estrutura HTML principal
├── package.json          # Configurações do Vite e scripts de build
└── README.md
```

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/henriqqw/Portfolio.git
   cd Portfolio
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Gere a versão de produção:**
   ```bash
   npm run build
   ```
